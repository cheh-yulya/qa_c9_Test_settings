## Тестовый репозиторий для практики клонирования по SSH
Это учебный репозиторий, созданный для отработки навыка работы с GitHub и учебной платформой.

### Что это за репозиторий?
Здесь нет кода приложения или автотестов — только этот файл README. Так сделано специально: чтобы вы сосредоточились на процессе клонирования, внесения изменений и отправки их обратно на GitHub.

### Что нужно сделать

1. Склонируйте этот репозиторий на свой компьютер, используя SSH-адрес.
    Как это сделать — описано в уроке.

2. Создайте файл hello.py в корне проекта со следующим содержимым: print("Hello, Git!")

3. Добавьте файл в индекс Git, сделайте коммит и отправьте изменения в удалённый репозиторий

4. Убедитесь, что файл hello.py появился на странице репозитория на GitHub.

**Если вы видите файл hello.py на GitHub после выполнения шагов — значит, вы успешно освоили клонирование по SSH, коммит и пуш.**
